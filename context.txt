SOURCE-OF-TRUTH PRINCIPLES
============================================================

Do not store:
- passwords
- Cloudflare API token values
- WireGuard private keys
- SSH private keys
- OPNsense private keys
- certificate private keys
- recovery codes

It is okay to document:
- secret location
- purpose
- provider/account
- required permission scope

Prefer declarative records for:
- hosts
- services
- networks
- dependencies
- firewall intent

Prefer snapshots for:
- live discovered state

Prefer runbooks for:
- outages
- recovery
- service-specific quirks

Prefer Git history for:
- why configurations changed

Always distinguish:

INTENT:
what the homelab should look like

STATE:
what discovery shows right now

This separation will make future Codex/OpenClaw management safer.
